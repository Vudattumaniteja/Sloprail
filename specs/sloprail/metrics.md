# Metrics - Sloprail

## North Star

Completed Stations that merge without timeline drift and require no re-explanation of human intent.

## Leading Metrics

- Station Handoff Validation pass rate.
- Average Representative Frames per Station.
- Agent-output validation pass rate.
- Merge success rate.
- Normalization changes per merged Station.

## Lagging Metrics

- Human Review Notes requiring rerender.
- Accepted Merged Outputs per Source Video.

## Diagnostic Metrics

- Candidate frames sampled.
- Near-duplicates rejected.
- Duration delta between Target Window and Replacement Render.
- FPS and resolution mismatches before normalization.
